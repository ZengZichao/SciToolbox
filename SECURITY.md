# Security Policy

## Supported versions

The latest release line (currently `1.x`) receives security fixes.

## Reporting a vulnerability

SciToolbox makes only outbound HTTPS requests to public academic APIs and collects no user data. If you discover a vulnerability — for example, unsafe handling of API responses, injection, or a dependency issue — please report it **privately** rather than opening a public issue.

- Email: `1073790321@qq.com`
- Once the repository is public, GitHub's private vulnerability reporting can also be used.

We aim to acknowledge reports within 7 days and provide a remediation timeline.
