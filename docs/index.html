SciToolbox

支持

macOS 15.0 或更高版本　·　版本 1.0.0

SciToolbox 把 UniProt、PDB、AlphaFold、PubMed、NCBI、Ensembl、KEGG、GO、Pfam、BacDive、GBIF、Europe PMC、GTDB 等公开学术数据库聚合成一个界面，让你用一次检索同时覆盖多个库。

常见问题

检索没有结果，或者提示网络错误

SciToolbox 不缓存数据库源数据，所有结果都来自公开接口的实时响应。因此请求失败通常有三个原因：网络不通、对应数据库暂时不可用、或者请求触发了该数据库的速率限制。

NCBI 系列接口（Taxonomy / Gene / PubMed）有较严格的访问频率限制，应用已内置最小 3 秒的请求间隔来规避，但在密集检索时仍可能偶发延迟。稍等片刻再试即可。

为什么有些数据库搜不到，只能按编号查？

不同数据库提供的检索能力差异很大。部分库（如 PDB、Pfam）以编号检索为主，对自由文本关键词支持有限。应用会尽量做关键词到编号的转换，但无法突破上游接口本身的限制。

我的收藏和历史记录存在哪里？

全部保存在你自己的 Mac 上，位于应用沙盒容器内。没有任何内容上传到服务器，详见 隐私政策。你可以用「设置」里的数据管理功能清除，也可以直接删除应用来彻底移除全部数据。

从旧版本升级后，之前的收藏不见了

上架版本开启了 macOS 应用沙盒，数据存储位置会迁移到沙盒容器内。开发版（自行编译）的数据位于容器外，沙盒应用无法读取，因此需要手工搬迁。如果你不需要旧数据，忽略即可，新版本会从零开始正常记录。

导出的文件格式有哪些？

支持 CSV 与 JSON（整表导出），以及 BibTeX、RIS 与 FASTA（引用与序列导出）。导出时由系统保存对话框决定存放位置，应用只能写入你明确选定的那一个文件。

应用会收集我的检索内容吗？

不会。检索词直接由你的 Mac 发往数据库服务器，不经过开发者，也无法与你的身份关联。应用内不含分析、广告或崩溃上报组件。
