隐私政策

生效日期：2026 年 9 月 16 日　·　最近更新：2026 年 9 月 16 日

SciToolbox 不采集你的任何个人数据。它没有账号系统、没有分析统计、没有崩溃上报，也不含任何广告或追踪组件。你的全部使用数据只保存在你自己的 Mac 上。

一句话总结：这个应用不知道你是谁，也不会试图知道。它只是一个查询公开学术数据库的本地客户端。

1. 我们不采集哪些数据

SciToolbox 不采集、不上传、不存储于任何服务器的数据包括：

  • 姓名、邮箱、电话或任何账户凭证（本应用没有账号系统）
  • 设备标识符、广告标识符（IDFA/IDFV）或任何可跨应用追踪的标识
  • 位置信息
  • 通讯录、日历、照片、麦克风、摄像头等系统权限数据（本应用不申请这些权限）
  • 使用行为统计、页面停留、点击埋点、崩溃日志

2. 数据保存在哪里

你的全部数据都保存在本机，且位于 macOS 应用沙盒容器内（~/Library/Containers/com.scitoolbox.app/）：

数据类型用途存储位置

删除应用即可完整清除上述全部数据。你也可以在应用内「设置」中随时手动清除收藏、历史或缓存。

3. 网络请求说明

SciToolbox 是一个只读的公开学术数据库客户端。当你发起检索时，应用会把你输入的检索关键词或编号通过 HTTPS 直接发送给对应的公开数据库接口，并取回结果。这是应用实现其唯一功能所必需的。

需要明确的是：

  • 请求直接由你的 Mac 发往数据库服务器，不经过开发者或任何中间服务器。
  • 开发者无法访问这些请求的内容，也无法将任何请求与你的身份关联。
  • 应用内置不包含任何 API 密钥，全部接口均为公开接口。
  • 请求仅用于实时获取本次检索结果，不用于任何其他目的。

4. 文件访问

当你使用导出功能（CSV / JSON / BibTeX / RIS / FASTA）时，应用会弹出系统的保存对话框，由你主动选择保存位置。应用只能写入你明确指定的那一个文件，无法读取或写入其他任何位置。

5. 第三方组件

SciToolbox 不包含任何第三方分析、广告或追踪 SDK。应用使用 Apple 系统框架（SwiftUI、Foundation、AppKit、CryptoKit）构建。

6. 儿童隐私

本应用不面向儿童设计，也不会有意采集儿童的任何信息。由于应用本身不采集任何个人信息，因此不存在此类风险。

7. 数据安全

由于应用不采集也不传输你的个人数据，因此不存在开发者侧的数据泄露风险。本机数据受 macOS 应用沙盒与系统文件权限体系保护。全部网络通信均强制使用 HTTPS，未配置任何明文传输例外。

8. 政策变更

若本政策发生实质性变更，我们会在本页面更新「最近更新」日期，并在应用的下一个版本中说明。继续使用应用即表示你接受更新后的政策。

Privacy Policy (English)

Effective date: September 16, 2026　·　Last updated: September 16, 2026

SciToolbox does not collect any personal data. It has no account system, no analytics, no crash reporting, and contains no advertising or tracking components. All of your data stays on your own Mac.

1. What we do not collect

SciToolbox does not collect, upload, or store on any server: names, email addresses, phone numbers, or any account credentials; device or advertising identifiers (IDFA/IDFV); location data; contacts, calendar, photos, microphone, or camera data (the app does not request these permissions); or usage analytics, behavioral telemetry, or crash logs.

2. Where your data is stored

All data is stored locally inside the macOS app sandbox container (~/Library/Containers/com.scitoolbox.app/). Favorites, search history, project collections, and preferences are stored in local UserDefaults. Cached API responses are stored in the local cache directory and expire automatically after two hours. Deleting the app removes all of this data completely.

3. Network requests

SciToolbox is a read-only client for public academic databases. When you run a search, the app sends your search keywords or accession numbers directly over HTTPS to the relevant public database API and retrieves the results. These requests go directly from your Mac to the database servers — they do not pass through the developer or any intermediary server. The developer cannot access the content of these requests and cannot associate them with your identity. The app bundles no API keys; every endpoint is public. Requests are used only to serve the current search in real time.

The app communicates only with the following HTTPS domains: rest.uniprot.org, www.uniprot.org, data.rcsb.org, search.rcsb.org, www.rcsb.org, cdn.rcsb.org, alphafold.ebi.ac.uk, eutils.ncbi.nlm.nih.gov, www.ncbi.nlm.nih.gov, pubmed.ncbi.nlm.nih.gov, www.europepmc.org, www.ebi.ac.uk, rest.ensembl.org, www.ensembl.org, rest.kegg.jp, www.kegg.jp, api.bacdive.dsmz.de, bacdive.dsmz.de, api.gbif.org, www.gbif.org, gtdb-api.ecogenomic.org, gtdb.ecogenomic.org, and doi.org. The privacy practices of these databases are governed by their own operators, not by this policy.

4. File access

When you export data (CSV, JSON, BibTeX, RIS, FASTA), the app presents the system save panel so that you choose the destination yourself. The app can write only to the file you explicitly select.

5. Third-party components

SciToolbox contains no third-party analytics, advertising, or tracking SDKs. It is built on Apple system frameworks (SwiftUI, Foundation, AppKit, CryptoKit).

6. Children's privacy

The app is not directed at children and does not knowingly collect information from children. Since the app collects no personal information at all, no such risk exists.

7. Data security

Because the app neither collects nor transmits personal data, there is no developer-side breach risk. On-device data is protected by the macOS app sandbox and system file permissions. All network communication is enforced over HTTPS, with no cleartext exceptions configured.

8. Changes to this policy

If this policy changes materially, we will update the "Last updated" date on this page and note the change in the app's next release. Continued use of the app constitutes acceptance of the revised policy.
